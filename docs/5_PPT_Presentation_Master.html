Problem Statement & Motivation
Speaker: Shaurya Dixit
Slide 2 / 15
Limitations of Standard Search & LLMs
  • Severe Hallucinations: Off-the-shelf models generate plausible but factually incorrect claims.
  • Knowledge Cutoff Windows: Foundation models cannot access newly revised academic syllabi or papers.
  • Keyword Search Blindness: Traditional searches match keywords but miss semantic context.
The Enterprise Need
  • Private, local institutional knowledge repositories.
  • Verifiable citations linking generated claims to exact document pages.
  • Compile-time type safety and ACID compliance using Java & PostgreSQL.
Arya College PBL (5th Sem) Slide 2 of 15
Proposed Solution: DocuQuery AI
Speaker: Shaurya Dixit
Slide 3 / 15
  • Full-Stack Architecture: Java 21 Spring Boot 3 microservice + Neon Cloud PostgreSQL + Electron 30 desktop client.
  • Deterministic Grounding: Strict prompt templates restrict generative responses to verified retrieved context passages.
  • Sub-100ms Vector Retrieval: Hierarchical Navigable Small World (HNSW) index on 1536-dimensional embeddings.
  • Continuous RAG Triad Evaluation: Continuous telemetry validating Faithfulness, Context Relevance, and Groundedness.
